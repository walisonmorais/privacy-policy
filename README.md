## 🛠️ Guia de Manutenção

Para adicionar ou atualizar uma política de privacidade, siga os passos abaixo:

### 🆕 Adicionando uma nova política
1. Crie um diretório com o nome do aplicativo em letras maiúsculas (ex: `APP_NAME`).
2. Adicione um arquivo `index.html` dentro desse diretório.
3. Certifique-se de que o HTML seja responsivo e contenha as informações legais necessárias.
4. Adicione a entrada correspondente na tabela de **Aplicativos Disponíveis** deste README.

### 🔄 Atualizando uma política existente
1. Localize a pasta do aplicativo.
2. Modifique o arquivo `index.html`.
3. Atualize a data de "Última Atualização" na tabela acima.
